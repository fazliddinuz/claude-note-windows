# Жамоа ҳисоботи — сервер

`note.py` мижозлари юборадиган ихчам ҳисоботларни қабул қилади, базага ёзади
ва дашбордда кўрсатади: ким, қайси лойиҳада, қачон, қанча.

Мижоз томони: `../README.md` → «Жамоа ҳисоботи (телеметрия)».

## Нима беради

- **Дашборд** — одам / лойиҳа / кун кесимида сарф, энг кўп ишлатилган воситалар.
- **Сессиялар** — ҳар бир сессия сана-вақти, сарлавҳаси ва қисқа хулосаси билан;
  одам, лойиҳа ва матн бўйича фильтр.
- **Лойиҳалар** — битта иш ҳар кимда ҳар хил номланган бўлса, номларни
  битта ном остига бирлаштириш (`/projects`, фақат бошқарувчига).
- **Огоҳлантиришлар** — қуйидаги 5 ҳолат, ҳар бирига «нима қилиш керак» изоҳи:

| Ҳолат | Қачон | Нега муҳим |
|---|---|---|
| Контекст жуда катта | ўртача контекст > 150K | сессия чўзилган, контекст ҳар сўровда қайта ўқилади — нарх шундан ошади |
| Кунлик сарф юқори | бир кунда > $40 | кун давомида нима бўлганини кўриш керак |
| Қиммат сессия | битта сессияга > $15 | одатда узун сессия ёки керагидан қиммат модель |
| Бегона лойиҳа | `KNOWN_PROJECTS` да ҳам, **/projects** рўйхатида ҳам йўқ | нима устида ишланганини аниқлаш |
| Тунги иш | маҳаллий вақт билан 00:00–06:00 | чарчоқ ва хато белгиси |

Чегаралар `.env` дан созланади.

## Тузилиши

```
app.py                 FastAPI: /ingest, /login, /, /sessions, /projects, /health
db.py                  SQLite (WAL) — ёзиш ва кесимлар
alerts.py              огоҳлантириш қоидалари
templates/ static/     интерфейс (ташқи CDN йўқ)
Dockerfile             python:3.12-slim, root эмас
docker-compose.yml     127.0.0.1:8095 → 8000, data/ volume
nginx.conf.example     проксилаш намунаси
deploy.sh              локалдан серверга чиқариш
test_server.py         115 та текширув
dev_run.py             локал синов (ҳақиқий сессияларни юборади)
```

## Локал синаш

```powershell
python test_server.py     # 115 текширув, вақтинчалик база
python dev_run.py         # http://127.0.0.1:8787  парол: dev
```

`dev_run.py` ҳақиқий транскриптлардан ҳисобот ясаб юборади — серверга аниқ
нима келишини кўрасиз. У ҳар сессияни **бутун** транскрипт бўйича ҳисоблайди,
шунинг учун суммалар `COSTS.md` дагидан катта чиқади (COSTS.md фақат
ишланган бўлакларни санайди). Продда ундай эмас — ҳар ишлов ўз бўлагини
юборади.

## API

### `POST /ingest`

```
Authorization: Bearer <токен>
Content-Type: application/json
```

Битта ёзув ёки ёзувлар рўйхати (кўпи билан 200 та). Жавоб:
`{"ok": true, "saved": 1, "duplicate": 0}`

- Мажбурий майдонлар: `member`, `project`, `session`, `date`.
- Оқ рўйхатдан ташқари ҳар қандай майдон **ташлаб юборилади** — базага фақат
  кутилган нарса тушади.
- Такрор юборилган ёзув (`session` + қатор оралиғи бўйича) жимгина ташланади:
  мижоз жавобни кутмай узилса, у ёзувни қайта юборади.
- Тана чегараси 64 KB (битта ҳисобот ~700 байт).

### `GET /health`

Аутентификациясиз: `{"ok": true, "reports": N, "first": ..., "last": ...}`

## Созламалар

Ҳаммаси `.env` дан — `.env.example` га қаранг. Кодда ҳеч қандай сир йўқ.

Мажбурий: `INGEST_TOKENS` (вергул билан бир нечта бўлиши мумкин) ва
`DASHBOARD_PASSWORD`.

Токен яратиш: `openssl rand -hex 32`

## Ишга тушириш

Серверни икки хил ишлатиш мумкин — ўзингизга қулайини танланг.

### (а) Ўз компьютерингизда (локал, бир киши ёки офис ичида)

Docker шарт эмас — оддий Python етарли:

```powershell
cd server
python -m pip install -r requirements.txt
$env:INGEST_TOKENS = "<openssl rand -hex 32 ёки исталган узун сатр>"
$env:DASHBOARD_PASSWORD = "<парол>"
python -m uvicorn app:app --host 127.0.0.1 --port 8095
```

Дашборд: <http://127.0.0.1:8095> (логин `admin`, парол — `DASHBOARD_PASSWORD`).
Мижоз томонида `config.json` → `telemetry_url`:
`http://127.0.0.1:8095/ingest`. Маълумот `server/data/` да туради
(`DATA_DIR` билан ўзгартирилади).

Docker бўлса — шу папкада:

```powershell
copy .env.example .env      # INGEST_TOKENS ва DASHBOARD_PASSWORD ни ёзинг
docker compose up -d --build
```

Порт фақат `127.0.0.1:8095` да очилади (`HOST_PORT` билан ўзгаради).

### (б) VPS'да жамоа билан (Docker + nginx + HTTPS)

Талаб: Linux VPS, Docker (compose плагини билан), nginx, certbot ва
сервер учун SSH алиас (`~/.ssh/config` да, масалан `my-vps`).

1. DNS: субдомен (масалан `your-server.example.com`) `A` → VPS IP.
2. Кодни чиқаринг (Git Bash / WSL / macOS / Linux терминалида):

   ```bash
   bash deploy.sh my-vps
   # ёки: DEPLOY_HOST=my-vps DEPLOY_DIR=/opt/claude-note-server bash deploy.sh
   ```

   Биринчи марта скрипт `.env` ни намунадан яратади ва тўхтайди — токен ва
   паролни ёзиб, қайта ишга туширинг:

   ```bash
   ssh my-vps
   cd /opt/claude-note-server
   nano .env
   docker compose up -d --build
   ```

3. nginx: `nginx.conf.example` ни `/etc/nginx/sites-available/` га кўчиринг,
   `SUBDOMAIN` ни ўз доменингизга алмаштиринг, кейин
   `nginx -t && systemctl reload nginx` ва `certbot --nginx -d <субдомен>`.
4. Мижозлар `telemetry_url` га `https://your-server.example.com/ingest`
   ёзади (ёки `note paket` уни пакетга ўзи қўяди).

**Муҳим:** серверда бошқа сайтлар ҳам бўлса, ҳар ўзгаришдан кейин
уларни текширинг:

```bash
nginx -t
for h in example.com app.example.com; do
  echo -n "$h "; curl -s -o /dev/null -w '%{http_code}\n' "https://$h/"
done
```

`deploy.sh` серверда `.env` ва `data/` га **тегмайди** — улар архивга кирмайди.

Жамоадошга токен қўшиш: `.env` даги `INGEST_TOKENS` га вергул билан
қўшинг ва `docker compose up -d` қилинг. `note paket "<исм>"` тайёр
буйруқни ўзи ёзиб беради (`config.json` → `server_ssh`, `server_dir`
ёки `CLAUDE_NOTE_SSH`, `CLAUDE_NOTE_SERVER_DIR`).

## Заҳира

Сақланиши керак бўлган нарса — фақат `data/` папкаси
(`telemetry.db` ва `secret.key`) ҳамда `.env`. Уни ўз заҳира
скриптингизга қўшинг.

## Лойиҳа номларини бирлаштириш

Лойиҳа номи ҳар кимнинг компьютеридаги **папка номидан** олинади. Шунинг
учун битта иш сизда `demo-project`, шеригингизда `DemoProject` бўлиб келади ва
ҳисоботда иккита алоҳида лойиҳа кўринади.

**/projects** (фақат бошқарувчига) — шу номларни битта ном остига қўйиш:

- **Бирлаштириш** — белгиланган номларни ёзилган умумий ном остига қўяди.
  Битта номни белгилаб янги ном ёзсангиз — **қайта номлаш** бўлади.
- **Рўйхатга қўшиш** — номини ўзгартирмай «бизники» деб белгилайди;
  шундан кейин у «Бегона лойиҳа» бўлиб огоҳлантирмайди.
- **Ажратиш** — бирлаштиришни бекор қилади, ҳар ном яна ўзича туради.
- Юқорида **таклифлар**: номлари ўхшаш (нормаллаштирилганда мос келадиган
  ёки бири иккинчисининг ичида, камида 5 белги) гуруҳлар кўрсатилади.

Муҳими:

- **Автомат бирлаштириш йўқ.** Бирлаштирилмаган ҳар бир ном ўз номи билан
  алоҳида туради — ўхшаш номли иккита бошқа лойиҳа жимгина қўшилиб
  кетмаслиги учун. Таклиф — таклифгина, қарорни одам қабул қилади.
- **Ҳеч қандай ёзув ўчмайди.** Хом ном қаторда қолади (`reports.project`),
  бирлаштирилгани алоҳида устунда (`reports.project_key`) туради. Шунинг
  учун «Ажратиш» ҳамма нарсани жойига қайтаради.
- Боғланиш `project_alias` жадвалида (`raw → canon`). Бирлаштирилгандан
  **кейин** келган ҳисоботлар ҳам дарҳол тўғри ном остига тушади.
- Дашбордда лойиҳа ёнидаги «N та ном» белгиси — жамоада шу иш шунча
  турлича номланганини билдиради.

## Фойдаланувчилар

Дашбордга ҳар ким **ўз логини** билан киради. Маълумот чегараланмайди —
ҳамма ҳаммасини кўради; алоҳида бўлгани фақат **кириш**, шунда одам
ишдан кетса фақат унинг логини ўчирилади.

- Рўйхат: `data/users.json` (паролнинг ўзи эмас, `pbkdf2-sha256` хеши).
- Бошқарув саҳифаси: **/users** — фақат «бошқарувчи» белгиси борларга.
  Одам қўшиш, янги парол бериш, ўчириш.
- Парол автомат яратилади ва **бир марта** кўрсатилади.
- Биринчи ишга туширишда `admin` ўзи яратилади, пароли — `.env` даги
  `DASHBOARD_PASSWORD`. Шунинг учун эски парол ишлайверади.
- Парол алмашса ёки одам ўчирилса — унинг очиқ сессияси **дарҳол**
  ёпилади (cookie имзосига парол изи киритилган).
- Охирги бошқарувчини ўчириб бўлмайди.

Терминалдан қўшиш (сайтга кира олмай қолсангиз):

```bash
ssh my-vps
docker exec claude-note-hisobot python -c "
import users
print(users.add('/data', 'yangilogin', member='Исми', admin=False))"
```

## Хавфсизлик

- `/ingest` — Bearer токен, солиштириш `hmac.compare_digest` билан.
- Дашборд — логин + парол; cookie HMAC билан имзоланади (`HttpOnly`,
  `SameSite=Lax`, HTTPS да `Secure`), 30 кун. Имзога парол изи киради,
  шунинг учун парол алмашса эски cookie яроқсиз бўлади.
- Парол `pbkdf2-sha256`, 200 000 итерация, ҳар кимга алоҳида туз (salt).
- Кириш формасидаги `next` фақат ички манзилга йўналтиради — ташқи
  сайтга ташлаб юборувчи очиқ редирект йўқ.
- Нотўғри паролда 1 сония кутиш — оддий brute-force секинлатгичи.
- Контейнер `root` остида эмас, порт фақат `127.0.0.1` да.
- Мижоздан хом транскрипт, код ва tool натижалари **умуман келмайди** —
  улар мижоз томонида фильтрланади (`../README.md` га қаранг).
